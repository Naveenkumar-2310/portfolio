# Naveen Kumar — Premium Personal Portfolio & AI Engineering Showcase

An Awwwards-inspired, high-performance portfolio crafted for **Naveen Kumar** (Software Consultant & Full-Stack AI Engineer). Built with **Next.js 16 (App Router)**, **React 19**, **TypeScript**, and **Tailwind CSS**.

---

## 🌟 Highlights & Key Features

- **Obsidian & Electric Aurora Design System:** Deep dark aesthetic with ambient glow shaders, dot-matrix patterns, and frosted glassmorphism (`backdrop-filter: blur(16px)`).
- **Interactive Particle Constellation Canvas:** High-efficiency `requestAnimationFrame` canvas with floating particles that connect with proximity laser lines and react to mouse movement.
- **Custom Magnetic Cursor Aura:** Smooth dual-layer cursor with magnetic snapping to buttons and interactive cards.
- **Floating Island Dock Navigation:** Responsive macOS-inspired dock with section tracker, live status beacon, and one-click **Resume PDF** download.
- **Interactive Bento Grid (Engineering DNA):** Highlighting the **9.10 CGPA** engineering foundation, software consultancy role at **Virdhi Tech Lab**, and an interactive skill taxonomy with filterable progress meters.
- **Production Systems Showcase:** 3D perspective cards with modal deep-dives for:
  - **Zenmarks.ai** (AI-Powered Educational Platform & Prompt Engineering)
  - **ZenSecure** (Security Operations & Guard Allocation Platform)
  - **Parenting** (Interactive Child Soft Skills Assessment)
  - **Virdhi Tech Lab** (Official Corporate Web Architecture)
- **Interactive AI Prompt Studio:** Real-time multi-stage generative AI pipeline simulator showcasing curriculum decomposition, real-world analogies, LaTeX mathematical models, and Bloom's Taxonomy question synthesis.
- **Laser-Guided Journey Timeline:** Illuminated milestone timeline tracking career and education.
- **Dual-Mode Contact Hub:** Direct one-click copy buttons for email (`pnaveenkumar.prasanna@gmail.com`) and phone (`+91 8220349415`), LinkedIn connect, interactive CLI terminal emulator (`naveen-kumar@shell`), and instant confetti transmission feedback.
- **Live Local Time:** Live clock showing local time in Chennai, TN, India.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally in Development Mode
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) (or the next available port shown in terminal).

### 3. Build for Production
```bash
npm run build
npm run start -- -p 3005
```
